## Current state

- The repository `isleofdan/compound-readings` (public, default branch `main`) holds one canonical, validated dataset: `data/compounds.json` (168 entries, `$schema_version` 1.0.0) consolidated by `npm run consolidate` from the four read-only source batches, with every transformation in `reports/01-migration.md`; `data/source/` is never edited.

- `data/chains.json` is a **proposed** whitelist of 30 chains (five with rules from `CLAUDE.md` §5, the rest `rule_reliability: "none"`); chain review happens in Dan's study project. `npm run build` runs validate → compact transform (`data/generated/compounds.compact.json`, gitignored, the only file the app imports) → regenerated index (`reports/03-index.md`) → type-check → bundle.
